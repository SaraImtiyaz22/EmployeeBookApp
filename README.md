# EmployeeBookApp

**EmployeeBookApp** is a simple Java console application designed to manage employee records efficiently. It supports operations like adding new employee details, updating existing records, deleting employee data, and displaying all stored employee information.

## Features

- Add new employee details (name, phone number, address, marital status, joining date, job title)
- Update existing employee records
- Delete employee records
- Display all employee data in a structured format
- Menu-driven interface for easy navigation

## Technologies Used

- Java (JDK 8+)
- Command-line (CMD)
- Git for version control
